# ADR-0002：不做外卖平台菜单数据接入

- 状态：已接受（2026-09-26）
- 关联：docs/2026-09-26-menu-library-research.md（调研依据）

## 背景

希望接入淘宝闪购/饿了么/美团等平台的商家菜单数据，降低录入成本。

## 调研结论

各平台开放 API（淘宝开放平台、美团点评餐饮开放平台）只面向**商家自管理**和**服务商**（需商家授权或企业资质，部分要求聚石塔环境）；**不存在读取他人商家完整菜单的公开 API**。联盟类接口（美团联盟/淘宝联盟）合法可得但只有推广元数据（店名/优惠/链接），无菜单内容。抓取/逆向链接解析存在反不正当竞争与违反平台协议的法律风险。

## 决策

1. MVP 及可预见迭代**不接入任何外卖平台菜单数据 API**
2. 合法的数据来源限定为：高德 POI（店铺骨架：店名/品类/坐标/距离）+ 用户导入（AI 拍照/截图/粘贴）+ 菜单包众包
3. 联盟推广元数据（优惠角标）列为远期可选项，不阻塞主线
4. 平台商务数据合作列为远期选项——发生前提是有规模化的真实用户量，届时再议

## 后果

- 正面：零合规风险；数据主权在用户；AI 拍菜成为录入主力的设计得到确认
- 代价：校外菜单新鲜度完全依赖用户维护（用 updatedAt + "多久前更新"展示缓解）
- 翻案条件：出现官方开放的数据合作通道，或用户量证明值得商务接洽
